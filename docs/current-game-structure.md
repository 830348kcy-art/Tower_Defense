# 현재 게임 구조 정리

이 문서는 현재 코드 기준의 맵 컨셉, 스테이지 구조, 타워, 적, 웨이브 구성을 한 번에 보기 위한 정리본이다. 상세 웨이브별 W1~W8 표는 [wave-composition.md](wave-composition.md)를 함께 참고한다.

## 기준 파일

| 구분 | 기준 파일 |
| --- | --- |
| 맵/스테이지/웨이브 | `Data/StageCatalog.cs` |
| 타워/업그레이드 | `Data/TowerCatalog.cs` |
| 적 능력치 | `Data/EnemyCatalog.cs` |

| 이미지 fallback | `Views/EnemyFallbackImageFactory.cs`, `Assets/Enemies` |

## 맵 컨셉

현재 맵은 20개 스테이지, 4개 챕터로 구성된다. 챕터가 올라갈수록 적 체력과 이동속도가 증가하며, 챕터 3부터는 환경 효과가 추가된다.

| 챕터 | 스테이지 | 테마 | 핵심 구조 | 체력 배율 | 속도 배율 |
| --- | --- | --- | --- | ---: | ---: |
| 챕터 1 | 1~5 | 초원 | 단일 직선 경로 | x1.000 | x1.00 |
| 챕터 2 | 6~10 | 숲 | 꺾이는 단일 경로 | x1.200 | x1.03 |
| 챕터 3 | 11~15 | 사막 | 2개 진입로가 중앙에서 합류 | x1.440 | x1.06 |
| 챕터 4 | 16~20 | 화산 | 긴 지그재그 단일 경로 | x1.728 | x1.09 |

## 맵 구조

- 맵 크기: `1100 x 620`
- 기본 시작 생명: `20`
- 시작 골드: `220 + (스테이지 - 1) x 12`
- 빌드 슬롯은 현재 코드상 빈 목록으로 생성되며, 실제 설치 가능 위치는 런타임 UI/맵 처리 쪽에서 확장될 수 있다.

| 챕터 | 경로 구조 |
| --- | --- |
| 1 | `(40,310) -> (560,310) -> (1060,310)` |
| 2 | `(40,100) -> (300,100) -> (300,310) -> (800,310) -> (800,520) -> (1060,520)` |
| 3 | 상단: `(40,150) -> (400,150) -> (550,310) -> (900,310) -> (1060,310)` / 하단: `(40,470) -> (400,470) -> (550,310) -> (900,310) -> (1060,310)` |
| 4 | `(40,80) -> (250,80) -> (250,540) -> (600,540) -> (600,120) -> (900,120) -> (900,540) -> (1060,540)` |

## 적 이미지 연결

- 우선순위는 개별 스프라이트 파일, 스프라이트 시트, 코드 fallback 이미지 순서다.
- 개별 파일은 `Assets/Enemies/Normal.PNG` 같은 적 이름 기반 파일을 우선 사용한다.
- 개별 파일이 없으면 `Assets/Enemies/EnemySpriteSheet.png`에서 잘라 쓰고, 그것도 없으면 코드가 직접 그린 기본 이미지가 표시된다.
- 팝업/도감 아이콘도 실제 적과 같은 이미지 우선순위를 사용한다.

## 웨이브 기본 규칙

- 각 스테이지는 W1~W8, 총 8개 웨이브로 구성된다.
- 다음 웨이브까지 기본 시간은 `22, 23, 24, 25, 26, 27, 28, 30`초다.
- 중간보스가 있는 스테이지는 W8 시간이 `34`초, 보스가 있는 스테이지는 W8 시간이 `40`초로 늘어난다.
- 적 수량은 목표 웨이브에 균등 분배하고, 나머지는 앞쪽 웨이브부터 1마리씩 더 배치한다.

## 전투 연결 규칙

- 물리 피해는 `PhysicalResist`, 마법 피해는 `MagicResist`의 영향을 받는다.
- 폭발 피해는 폭발 타입으로 처리되며, 와이번은 폭발 피해를 무시한다.
- 와이번은 병영 병사가 교전 대상으로 잡지 못하고, 이미 교전 중이어도 다음 틱에 풀린다.
- 분열형 적은 사망 시 현재 위치와 경로 진행 상태를 기준으로 자식 적을 생성한다.
- 보스가 존재하면 게임 화면 왼쪽 위에 보스 체력 UI가 표시된다.
- 적 팝업은 신규/재등장 탭으로 나뉘며, 특수 능력이 있는 적은 설명 텍스트를 함께 보여준다.
